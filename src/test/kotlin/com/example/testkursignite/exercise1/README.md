# Oppgave 1 – Testdata (Object Mother)

- **Test:** `OrderTest.kt`
- **Produksjonskode:** `src/main/kotlin/com/example/testkursignite/exercise1/Order.kt`
- **Løsningsforslag:** `solution/` (ikke kikk før du har prøvd selv)

Testene sjekker fraktkostnad og totalpris for en ordre, men det er vanskelig å se *hva* hver test egentlig handler om.

1. Lag en `OrderMother` som gir deg gyldige objekter med fornuftige standardverdier.
2. Skriv om testene slik at hver test bare viser det som er relevant for den.
3. Gi testene navn som beskriver oppførselen.
